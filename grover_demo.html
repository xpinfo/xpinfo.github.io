Grover’s Algorithm Demo

A classical simulation of Grover’s algorithm demonstrates how a quantum computer can search an unsorted list of N items using roughly the square root of N steps, compared with about N/2 steps on average for a conventional computer.

1 · Select a search space

The list has N = 2ⁿ items. The marked item is the single entry the search is trying to find. The algorithm does not know which one it is; it can only ask an oracle whether a given item is the marked one.

2 · Probability of each item

Each iteration applies the oracle, which flips the sign of the marked item’s amplitude, followed by the diffusion step, which reflects every amplitude about the average. Together they raise the marked item’s probability (orange) and lower the others (purple).

Note: this page runs entirely within the web browser. No data are transmitted, and no quantum hardware is used; all results are simulated for demonstration. Grover’s algorithm provides a quadratic speedup for unstructured search, not the exponential speedup associated with Shor’s algorithm.
